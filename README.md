# Employee Management System

A full-stack Employee Management System built with React and FastAPI, featuring employee management, authentication, and a PostgreSQL database.

## 🚀 Live Demo

- **Frontend Application:** https://employee-management-apiii-2.onrender.com
- **Backend API:** https://employee-management-apiii.onrender.com
- **API Documentation:** https://employee-management-apiii.onrender.com/docs

## 🛠️ Tech Stack

- **Frontend:** React, Vite, JavaScript
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL
- **ORM:** SQLAlchemy
- **Authentication:** JWT
- **Deployment:** Render

## ✨ Features

- User authentication and login
- Employee management
- REST API integration
- PostgreSQL database connectivity
- Responsive web application
